REST API Guide

Facility location solver integration via cURL

Demo data is generated at startup. The solver keeps a single in-memory problem; endpoints below operate on that problem.

1. Get the current status and solution

            
            curl -X GET -H 'Accept:application/json' http://localhost:8080/flp/status

2. Start solving

            
            curl -X POST http://localhost:8080/flp/solve

3. Poll until solving finishes

            
            curl -X GET -H 'Accept:application/json' http://localhost:8080/flp/status

4. Fetch the analysis of the solution

            
            curl -X PUT -H 'Content-Type:application/json' http://localhost:8080/flp/analyze

5. Terminate solving early

            
            curl -X POST http://localhost:8080/flp/stopSolving
